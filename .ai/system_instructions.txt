# IssueFlow Backend - AI System Instructions Profile

## 1. Code Style & Architecture Constraints
- Framework: NestJS 11.x, TypeScript 5.x.
- Architecture: Controller-Service-Repository pattern with strict layer encapsulation.
- Validation: Enforce absolute input-output validation using class-validator and class-transformer.
- Documentation: Complete Swagger decoration on DTOs and Controllers; maintain pure Entity definitions.

## 2. Memory & Performance Efficiency
- Prevent unnecessary memory allocations during heavy database reads.
- Leverage selective field queries to explicitly omit sensitive data (e.g., user passwords).
- Implement explicit database indexing on foreign keys used frequently in filter queries.

## 3. Concurrency & Data Integrity
- Mitigate data race conditions and stale overwrite anomalies across transactional models.
- Implement Optimistic Locking utilizing TypeORM '@VersionColumn' for shared entities (Tickets, Comments).
- Enforce immutable, strict, forward-only state machines across shared business components.

## 4. Error & Exception Handling
- Zero unhandled exceptions. Map every edge case to explicit NestJS HTTP Exceptions.
- Gracefully intercept relational or database constraint failures and translate them into secure, actionable API payloads.
